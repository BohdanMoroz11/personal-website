# V2 — Visual redesign & port plan

> **Branch:** `v2` — all V2 work lands here as incremental commits. No separate PRs; merge to `main` when ready to ship.
>
> **Reference mockup:** [`V2_REFRENCE.html`](../V2_REFRENCE.html) (pure HTML+CSS+JS, ~90% final on visuals and copy)

## Why V2 exists

V1 shipped polished: solid copy, clean Astro code, full test/CI/Lighthouse coverage. The intentional trade-off was a **safe, editorial, paper-letter aesthetic** — professional but visually forgettable.

V2 keeps the same substance (freelance positioning, US SMB domains, project portfolio, contact funnel) but **leans into a distinctive, memorable visual identity**: dark tactical-terminal / cyber-industrial vibe with subtle atmosphere, motion, and information-dense layout.

V1 remains on `main` until V2 is ready to replace it.

## Visual direction (from mockup)

### Aesthetic

- **Dark-only palette** — mid-dark blue-grey base (`#191e24`), layered panel surfaces, crisp hairline borders
- **Accent:** warm signal red (`#e0563d`, "Arasaka red" against cool bg)
- **Typography:** [Chakra Petch](https://fonts.google.com/specimen/Chakra+Petch) (display/headings) + JetBrains Mono (labels, nav, terminal chrome). Replaces V1's Newsreader + Inter.
- **Layout width:** `1180px` max (V1 was `760px` article card)
- **Atmosphere:** fixed faint grid + scanline overlay (decorative, `pointer-events: none`)
- **No light/dark theme toggle** in the mockup — single dark theme

### Motion & interaction (preserve in port)

| Effect                   | Where            | Notes                                                                                          |
| ------------------------ | ---------------- | ---------------------------------------------------------------------------------------------- |
| Bootline typewriter      | Hero             | `> bohdanmoroz.com — sofia, bulgaria — available for work` with green status + blinking cursor |
| Live clock               | Topbar           | Sofia time, `UTC+2`, updates every second                                                      |
| Signal-lock reveal       | Section blocks   | Elements start dim/desaturated, sharpen in place on scroll (IntersectionObserver)              |
| Edge accent line         | Locked blocks    | 2px left border snaps from dark red → signal red                                               |
| Decrypt scramble         | Section headings | `data-decrypt` headings resolve from random glyphs on first reveal                             |
| Accordion dossier        | Project cards    | One open at a time; first case open by default; `aria-expanded` on buttons                     |
| `prefers-reduced-motion` | Global           | Skip animations; show final text immediately; hide cursor blink                                |

### Responsive breakpoints (from mockup)

- `920px` — hide top nav links, 2-col spec grid, single-col protocol/contact
- `620px` — tighter section padding, smaller decrypt-safe headings, condensed cells
- `560px` — hide case metric numbers in accordion header
- `380px` — smallest section titles, hide trailing rule line

### New chrome

- **Sticky topbar:** brand mark (`B` in signal box), section nav (`01 Protocol`, `02 Dossier`, `03 Channel`), live clock
- **Section headers:** `§ NN` badge + uppercase title + horizontal rule + mono subtitle (`<< … >>`)

### Content structure updates (dictionary shape will change)

The mockup reshapes several data models:

**Hero**

- Split display name: `Bohdan` / `Moroz` (two lines)
- Tagline with `//` separator
- Email CTA button (not inline text link)
- 6 spec cells: Experience, Domains, Core stack, Infra, Languages, Employer

**Protocol** (was `howIWork`)

- 2×2 grid of cells labeled A–D with names: Ownership, Stack, Throughput, Comms
- Bold lead-ins in body copy

**Dossier** (was `work.projects`)

- Accordion `article.case` per project
- Header: numeric ID, name, role badge, optional `● Live`, tease line, metric (number + caption), chevron
- Expanded: description, `// stack manifest` tag list, years footer, link (`Open record ↗` / `Closed record`)
- Metrics are structured (`635` / `Drivers · 8 carriers`) not a single string

**Open Channel** (was `contact`)

- Two-column grid: pitch + mailbtn | Location, In person, Network, Clearance (green status)

**Footer**

- Language pills (EN/RU/UK)
- GitHub + LinkedIn buttons
- Signature: `BM // BOHDANMOROZ.COM — NO CORPORATE AFFILIATION`

## What we keep from V1

- **Stack:** Astro 6 static, Tailwind CSS 4, TypeScript, no JS framework
- **i18n routing:** Astro built-in locales (`en` unprefixed, `ru/`, `uk/` prefixed) + JSON dictionaries
- **SEO infrastructure:** `Base.astro` meta, canonical, hreflang, OG tags, JSON-LD schema
- **Quality bar:** ESLint, Prettier, Vitest, Playwright e2e, Lighthouse CI — update tests to match V2, don't drop coverage
- **Single-page scope** — still one index per locale + 404

## Suggested port phases

Work through these on `v2` as separate commits:

1. **Design tokens & global styles** — port `:root` vars, atmosphere layers, base typography, responsive rules from mockup CSS into `src/styles/global.css` (replace V1 tokens)
2. **Layout shell** — update `Base.astro`: new fonts, meta theme-color; comment out theme-toggle script/UI (keep code for future light theme)
3. **Topbar component** — brand, nav anchors, clock (client script)
4. **Hero + spec strip** — markup, i18n keys, bootline script
5. **Protocol section** — new component + dictionary keys
6. **Dossier accordion** — new component + restructured project data in locale JSON + accordion/decrypt/lock scripts
7. **Open Channel** — contact grid component
8. **Footer** — lang pills, social, signature (reuse/adapt `LangSwitch.astro`)
9. **i18n** — reshape `en.json`, propagate to `ru.json` / `uk.json` (parity test will enforce shape)
10. **Client JS** — extract inline mockup scripts into minimal modules or `<script>` blocks in components; respect `prefers-reduced-motion`
11. **Tests & CI** — update e2e selectors, axe checks, Lighthouse paths; comment out theme-toggle tests (keep for future light theme)
12. **Cleanup** — delete unused V1 components/styles, remove `V2_REFRENCE.html` from repo when port is verified (or move to `docs/` archive)
13. **Polish pass** — a11y (focus states, keyboard accordion), perf (font loading, no layout shift on decrypt), SEO (update schema copy)

## Decisions (locked in)

- **Single dark theme for now.** Not pitch-black — mid-dark blue-grey from the mockup. Theme toggle and light-mode CSS/tests are **commented out, not deleted**; a separate light theme may come later.
- **CSS:** proper Tailwind `@theme` tokens + component utility classes. Showcase-quality code, not verbatim mockup CSS dumps.
- **i18n:** reshape and fill `en.json` first (mockup is EN-only). `ru.json` / `uk.json` backfilled after EN port is stable.
- **Reference file:** keep `V2_REFRENCE.html` at repo root during port.
- **Favicon / OG image:** deferred.
- **404 page:** restyle to match V2 (during polish phase).

## Acceptance criteria

V2 is done when:

- Visual parity with `V2_REFRENCE.html` at desktop, tablet, and mobile breakpoints (allow minor sub-pixel differences)
- All three locales render with dictionary parity
- `npm run test:all` passes (updated for V2 behavior)
- Lighthouse floors still met (perf ≥ 0.95, a11y 1.0, best-practices ≥ 0.95, SEO 1.0)
- No regressions in SEO meta, hreflang, JSON-LD
- Motion respects `prefers-reduced-motion`
- Accordion is keyboard-accessible
